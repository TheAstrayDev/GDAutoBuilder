# Rhythm Layout Builder — Geode / Geometry Dash

**Экспериментальная исходная версия (v0.1), для Android.** Это не готовый APK и не собранный `.geode`-мод. Код требует сборки и проверки в игре на соответствующей версии Geode/Geometry Dash.

## Что делает

- Добавляет видную кнопку **GEN** в редакторе уровней.
- Открывает выбор **22 официальных песен** и 6 сложностей с иконками GD: Easy / Normal / Hard / Harder / Insane / Demon.
- **GENERATE** создаёт геометрию, препятствия и орбы; добавляет порталы, ритмические триггеры Pulse / Move / Shake, анимирует декоративные группы и отдельные игровые платформы.
- Расставляет простые декоративные блоки по ритмическим меткам.
- **IMPROVE** до трёх раз делает дополнительный проход по промежуткам между препятствиями, добавляет орбы и световые акценты. Не удаляет существующие объекты.
- Не меняет существующий уровень: генерация разрешена только в **пустом** редакторе.

## Что важно понимать

- **Настоящее чтение всего трека:** только при наличии файла `song_<индекс>.wav` в `Mod::get()->getSaveDir()` (индексы 0–21 соответствуют порядку песен в меню). Анализатор читает PCM WAV (8/16-bit, mono/stereo) и выделяет всплески громкости. При отсутствии WAV используются **приблизительные BPM и длительность**, а не анализ реальной песни.
- Анализатор музыки — простой onset detection по энергии, **не** выделяет инструменты, структуру песни или сложные паттерны.
- Длина и размещение зависят от приблизительной скорости уровня; **идеальная проходимость не гарантирована**. Обязательно тестировать лайаут вручную!
- Не используются все триггеры игры: есть **Move (901), Pulse (1006), Shake (1520)**, в том числе Move для игровых платформ. Остальные триггеры требуют отдельной логики.
- Кнопка **IMPROVE** — детерминированный эвристический алгоритм анализа пробелов, **не облачный ИИ** и не умеет автоматически играть или доказывать проходимость.
- Автоматического декодирования защищённых/встроенных аудиоресурсов игры нет. Файлы песен не включены.
- Мод рассчитан в первую очередь на **GD 2.2081 / Geode 5.8.2**; совместимость с установленной на телефоне версией требуется проверить.
- Размер PCM WAV ограничен 64 МиБ для экономии памяти; при превышении этого размера будет использован BPM-пресет.

## Как собрать Android `.geode` (через GitHub Actions)

1. Исходники размещены в [TheAstrayDev/GDAutoBuilder](https://github.com/TheAstrayDev/GDAutoBuilder). Workflow находится в `.github/workflows/android.yml`.
2. Открой вкладку **Actions**, выбери **Android builds** и нажми **Run workflow** (либо произойдёт сборка при push).
3. При успешной сборке в **Artifacts** появится `rhythm-builder-Android64` или `rhythm-builder-Android32`. Скачай архив и извлеки из него `.geode`-файл.
4. Положи `.geode` в папку модов Geode на устройстве (пример для Android: `/storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods/`) или воспользуйся менеджером модов в Geode.
5. Запусти Geometry Dash -> Создать -> Редактор **пустого уровня** -> нажми **GEN**.

Workflow сначала запускает тесты ядра и WAV-анализатора, затем собирает Android32 и Android64 с Geode SDK из `mod.json`. Результаты сборок доступны во вкладке [Actions](https://github.com/TheAstrayDev/GDAutoBuilder/actions/workflows/android.yml). Успешная компиляция не заменяет проверку мода в игре на Android; такая проверка пока не выполнена.

## Дополнительный анализ трека

Ты можешь использовать WAV из собственной законной копии трека. Для преобразования в PCM WAV требуется `ffmpeg`:

```bash
python tools/prepare_wav.py /path/to/my-audio.ogg /path/to/song_0.wav
```

Скопируй `song_0.wav` в директорию сохранений мода; `0` — Stereo Madness, `1` — Back on Track, и так далее.

## Проверка алгоритма без SDK

```bash
g++ -std=c++23 -O2 -Wall -Wextra src/GeneratorCore.cpp tests/test_core.cpp -o test_core
./test_core
g++ -std=c++23 -O2 -Wall -Wextra src/GeneratorCore.cpp tests/test_wav.cpp -o test_wav
./test_wav
```

Проверяется только **независимый от GD модуль алгоритма** — не кнопки, не запись объектов в игру и не Android-сборка.

## Разработчикам

- `src/GeneratorCore.hpp`, `src/GeneratorCore.cpp` — ритмические метки, генерация, усиление.
- `src/main.cpp` — UI Geode, создание игровых объектов и установка свойств триггеров.
- `mod.json`, `CMakeLists.txt` — настройки сборки.
- `.github/workflows/android.yml` — сборка под Android32/64.
